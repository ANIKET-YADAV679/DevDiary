DevDiary - Developer Learning Tracker
Hi! I’m a 1st-year CSE student, and this is my first full-stack web project. I built this to help me keep track of all the things I learn every day, from LeetCode problems to Spring Boot debugging.

Why I built this
I realized that I often forget what I learn after a few days. I wanted a way to stay accountable and keep a record of my progress that I can eventually show in my portfolio!

Tech Stack
Frontend: HTML, CSS, JavaScript (Vite + React coming soon!)

Backend: Spring Boot (currently setting this up)

Database: PostgreSQL

Deployment: Vercel & Render

Features
Daily learning log entry.

Category tagging (DSA, Full Stack, Other).

Confidence rating for each topic.

Streak tracker (Work in progress!).

How to run it
Clone the repo: git clone [https://github.com/ANIKET-YADAV679/DevDiary.git](https://github.com/ANIKET-YADAV679/DevDiary.git)

Open index.html in your browser.

Built during Summer Camp 2026. Learning something new every day!
